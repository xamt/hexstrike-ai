# HTTP 工具技能 — 需求

## 核心目标
把现有 MCP 工具调用层转换为 Agent 技能，直接请求现有 HTTP 服务。

## 功能边界
保留全部工具参数、默认值、条件转换、请求顺序及返回聚合；保留原 MCP 文件。

## 非目标
不修改服务业务、镜像，不构建镜像、不运行扫描或访问真实工具服务。

## 技术约束
技能运行仅需 Node.js 22+ 内置 API，不依赖本机 Python、MCP SDK 或 npm 包。开发时可用 Python 标准库提取原脚本及运行离线对照。

## 质量要求
全量工具离线行为对照、HTTP 错误和超时检查、参数校验、技能验证。明确原脚本缺陷及兼容策略，不静默丢弃工具。
