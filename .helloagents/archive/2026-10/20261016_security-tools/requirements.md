# 五项安全工具补充 — 需求

## 核心目标
补充已确认的 testssl.sh、WhatWeb、JWT-Tool、TruffleHog、tcpdump，并让服务端与项目技能的声明对应实际工具。

## 功能边界
固定版本安装、构建末尾校验、基础镜像版本 1.2.0、应用引用与构建文档同步；补齐五项专用 HTTP 路由、健康检查及技能调用声明。

## 非目标
不构建或运行镜像，不开展真实扫描，不升级已有工具，不修改已有 JWT 分析接口行为，不扩大到其他工具。

## 技术约束
保留 AMD64/ARM64 独立构建方式，版本定义靠近安装脚本；JWT-Tool 使用独立虚拟环境；服务扩展独立模块，原服务只接入注册入口。

## 质量要求
参数验证、无 shell 执行、有界超时/输出/并发，不缓存或记录令牌与工具输出；离线测试覆盖命令生成、失败路径和技能契约一致性。
