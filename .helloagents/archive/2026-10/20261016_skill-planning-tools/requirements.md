# 技能工具与测试闭环 — 需求

## 核心目标
核对并封装新增数据库工具；模型先规划再测试，快速复核疑点，围绕已验证根因深化影响评估。

## 功能边界
保持现有工具调用契约；规划、优先级、验证和深挖须成为技能执行流程，不只是提示口号。

## 非目标
不执行镜像构建或真实扫描，不虚构缺失的 API。

## 技术约束
用户已确认本轮新增五个 HTTP 接口并接入技能。三个 SQL 引擎执行 SQL，Redis 执行命令数组，MongoDB 执行命令对象；不强制只读，不新增 MCP 注册。

## 质量要求
离线契约回归、引用校验、技能格式和独立情境推演已通过；区分已验证影响与潜在关联，未执行在线验收。
