# MCP 工具目录

这里集中维护 MCP 工具声明，通过 `register_tools(mcp, tool_client)`
注册到 Streamable HTTP 服务，不维护额外的传输分支或工具副本。

- 保留原有 151 次工具声明和注册顺序。原文件重复声明了 `httpx_probe`，所以唯一
  MCP 工具名称为 150 个；同名处理由运行层保持原 SDK 的首次注册语义。
- 各领域注册函数通过闭包绑定服务实例的客户端，不使用全局可变客户端。威胁情报
  的两个互相引用工具保持在同一闭包中。
- 注册函数是机械迁移的声明容器，其长度属于生成迁移例外。原有长工具函数也按
  机械迁移例外保留，避免为调整行数而改变工具执行逻辑。
- `tests/fixtures/mcp-tool-contract.json` 冻结迁移前每份声明的参数 AST、返回类型、
  原始文档字符串和函数体 AST 哈希。改动工具行为必须显式审查，不能无条件刷新基线。
- 原有业务缺陷不会在传输迁移中隐式修复。例如两个复合工具中的未定义 `self`
  引用仍保留；发现工具不等于保证所有历史工具执行成功。
- HTTP 技能导出器从真实注册入口读取模块顺序，仅在构建时解析 AST；MCP 运行时
  不解析或执行 AST，也不加载历史单文件源码。
